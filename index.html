// FEATURED PROJECT

Selected work.

CAPSTONE SYSTEM WEB PLATFORM SQL DATABASE

A Web-Based Appointment and Inventory System for Berberabe Pastor Dental Clinic

A full-stack capstone web platform designed for Berberabe Pastor Dental Clinic in Batangas City. It replaces manual appointment logbooks and paper-based supply tracking with a unified digital system—giving patients an effortless booking experience and giving clinic staff real-time visibility over schedules and dental inventory.

PROJECT HIGHLIGHTS

01

Online Appointment Scheduling

Patient-facing booking flow with clinic hours status, service selection, and organized appointment queues.

02

Real-Time Inventory Tracking

Centralized monitoring of dental consumables and supplies with stock-level tracking to prevent shortages.

03

Relational SQL Architecture

Structured database connecting patient records, appointment histories, services, and inventory logs.

04

Patient-First Interface

Clean, responsive layout built for clear clinic communication, service discovery, and quick sign-up.
